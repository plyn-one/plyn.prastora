What the editorial page tests

Without headers, menus, map controls or JavaScript, a site can use the same layout vocabulary and reuse a news-card module. The composition is explicitly set for each frame, not by a fluid CSS grid.

Check the reading width on a very wide screen. It should not collapse to a narrow sliver or unexpectedly rearrange its prose.

One framework, more than one visual language.

# Prastora v0.2.0-rc1 release candidate

Status: **candidate only**, not an official tag, release or production-site acceptance. It extends v0.1.7 with optional header, forms, news, languages, video and map modules, and check.mjs --site. The strict mode remains available.

Public GitHub Actions runs core and module Chromium regressions before release/package.mjs and uploads a tar.gz candidate. SHA256SUMS lists each public bundled file and RELEASE-CANDIDATE.md identifies the exact tested commit. No private data or third-party map runtime is included.

Final v0.2.0 requires a green package check, an immutable v0.2.0 Git tag created through the authorized Plyń Klucnik, version-derived README/CONNECT/site/v0.2.0 built from that tag, and owner-frame deployed browser acceptance. The current Klucnik has no tag operation. Until a verified tag exists, pin the exact commit; do not use nonexistent @v0.2.0 CDN links.

The Ramonak adapter is optional. Another backend may render the same HTML. Production map tiles need a licensed service.
